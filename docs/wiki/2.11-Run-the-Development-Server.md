# Run the Development Server

How to run Ultra Tasks locally for development, or in GitHub Codespaces.

## Option 1: Local

### Prerequisites

- Node.js 22.22.3+, 24.15.0+ or 26+ ([nodejs.org](https://nodejs.org)); `.nvmrc` pins the version CI uses
- Git

### Local: Clone and Install

```bash
git clone https://github.com/ac9492/ultra-tasks.git
cd ultra-tasks
npm ci
```

### Local: Start the Frontend

```bash
npm run startFrontend
```

`npm run startFrontend` regenerates the environment constants from `.env` and starts the Angular dev server; see [[2.16-Set-Up-Development-Environment]]. Open [http://127.0.0.1:4200](http://127.0.0.1:4200). For most UI and frontend work this is enough. [Redux DevTools](https://chrome.google.com/webstore/detail/redux-devtools/lmhkpmbekcpmknklioeibfkpmmfibljd) work in the browser.

### Local: Run the Full App (Electron)

```bash
npm run startFrontend
```

In a second terminal:

```bash
npm start
```

`npm start` compiles the Electron main process and opens an Electron window that loads the dev server.

## Option 2: GitHub Codespaces

1. Open the repository on GitHub.
2. Click **Code** → **Codespaces** → **Create codespace on main** (or the plus icon).
3. Wait for the dev container to build. The development server usually starts automatically.
4. Open the **Ports** tab, find the forwarded port (e.g. 4200), and use **Open in Browser** or Ctrl+Click the URL to open the app.

VS Code settings sync in the codespace. To change the dev environment, edit
`.devcontainer/devcontainer.json` per the
[Codespaces documentation](https://docs.github.com/en/codespaces/setting-up-your-project-for-codespaces/adding-a-dev-container-configuration/introduction-to-dev-containers).
