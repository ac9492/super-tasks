# Downloads and Install

Ultra Tasks is independently maintained by Adrian Chase. Download published desktop builds from the [Ultra Tasks GitHub releases](https://github.com/ac9492/ultra-tasks/releases). Choose the Setup installer or the Portable app for Windows, or for macOS the DMG or ZIP for Apple Silicon (`arm64`) or Intel (`x64`), or the universal DMG that runs on both. `SHA256SUMS.txt` lists a checksum for every download.

Only Windows and macOS builds are published. There are no Ultra Tasks builds for Linux, Android, or iOS, and no listings in app stores, Snap, or Flatpak; on those platforms, build from source (see below).

Windows builds are currently unsigned. macOS builds are ad-hoc signed and are not notarized, so Windows SmartScreen or macOS Gatekeeper may ask you to confirm before the app opens; on macOS, use **System Settings → Privacy & Security → Open Anyway** if needed. See the [desktop build guide](https://github.com/ac9492/ultra-tasks/blob/main/docs/ultra-tasks-builds.md) for installation details and build commands.

The planned website is [ultratasks.app](https://ultratasks.app). Hosting and independent app-store listings are being set up separately. Super Productivity's existing store listings and package-manager entries install the upstream app.

## Existing data

Ultra Tasks can coexist with Super Productivity. To transfer upstream tasks, export a backup from Super Productivity and explicitly import it into Ultra Tasks. Keep the original backup.

Existing desktop profiles from this fork's former Super Tasks name are reused automatically when no Ultra Tasks profile exists. See [[3.06-User-Data]].
