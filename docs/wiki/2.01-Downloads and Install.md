# Downloads and Install

Ultra Tasks is independently maintained by Adrian Chase. Download published desktop builds from the [Ultra Tasks GitHub releases](https://github.com/ac9492/ultra-tasks/releases). Choose the installer or portable app for Windows, or the matching Intel/Apple Silicon package for macOS.

Windows builds are currently unsigned. macOS builds are ad-hoc signed and are not notarized; see the [desktop build guide](https://github.com/ac9492/ultra-tasks/blob/main/docs/ultra-tasks-builds.md) for installation details and build commands.

The planned website is [ultratasks.app](https://ultratasks.app). Hosting and independent app-store listings are being set up separately. Super Productivity's existing store listings and package-manager entries install the upstream app.

## Existing data

Ultra Tasks can coexist with Super Productivity. To transfer upstream tasks, export a backup from Super Productivity and explicitly import it into Ultra Tasks. Keep the original backup.

Existing desktop profiles from this fork's former Super Tasks name are reused automatically when no Ultra Tasks profile exists. See [[3.06-User-Data]].
