# Import from TickTick

Bring your open TickTick tasks, sub-tasks, checklists, tags and due dates into Ultra Tasks in one pass. The import is **additive**: it only creates new projects, tags and tasks and never changes or removes existing Ultra Tasks data.

## What you need

- A **TickTick backup file**: in the TickTick web app, open **Settings → Backup** and click **Generate backup**. This downloads a `.csv` file. The file is read on your device only; nothing is uploaded.

## Steps

1. Open **Settings → Import & export** and choose **TickTick** in **Import from**.
2. Follow the displayed export instructions, then choose the backup CSV file.
3. Review the project and task counts. Closed tasks are excluded.
4. Select **Import tasks**. The importer runs inside Settings; no plugin is required.
5. Check the imported projects before importing another copy of the same file. Re-importing creates duplicates.

## What is imported

- Lists, as projects (folders are flattened; lists with the same name in different folders become `Folder / List`; the TickTick Inbox becomes a project named “Inbox (TickTick)”)
- Open tasks and sub-tasks (Ultra Tasks nests two levels; deeper sub-tasks become direct sub-tasks of their top-level task)
- Checklist items, as sub-tasks of top-level tasks (checked items are imported as done). On sub-tasks the checklist is kept as a markdown checklist in the notes.
- Task content (into task notes)
- Tags (on top-level tasks)
- Due dates, including times
- Recurring tasks keep their next due date; the recurrence rule is added to the task notes (e.g. `Repeats: RRULE:FREQ=WEEKLY;INTERVAL=1`)

## Priorities

Priorities become tags on top-level tasks: high → p1, medium → p2, low → p3. Subtasks do not receive tags. No Eisenhower mapping is applied.

## What is not imported

- Completed, archived and won't-do tasks, and lists that contain only such tasks
- Folders and kanban columns (task order is preserved)
- Tags and mapped priorities on sub-tasks
- Reminders
- Recurrence rules as real repeating tasks — recreate important ones via [[2.06-Manage-Repeating-Tasks]]
- Attachments, comments, focus records and habits (they are not part of the TickTick backup)

Unusually long list names, task titles, tags and task notes are shortened to safe import limits. The preview reports how many values are affected.

The importer reads the column names of an English backup. If it reports that the file is not a TickTick backup and TickTick is set to another language, try switching TickTick to English and generating the backup again.

If the import stops midway, delete the project named in the error because it may be incomplete. Delete any projects from that file that were already imported before retrying the file. To undo an import, delete the created projects.
