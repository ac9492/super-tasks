# Import from Todoist

Bring tasks from a Todoist project CSV into Ultra Tasks. The import is **additive**:
it creates a new project and never changes or removes your existing tasks.
The importer is built into Settings; no plugin or API token is required.

## What you need

A Todoist project CSV. In Todoist on web or desktop, open the project, select the
three-dot menu, then **Import & export → Export to CSV**. Export each project you
want to move separately. See [Todoist's export instructions](https://www.todoist.com/help/account-and-billing/security/import-or-export-a-project-as-a-csv-file-in-todoist-YC8YvN).

## Steps

1. Open **Settings → Import & export**.
2. Choose **Todoist** in **Import from**. Its export instructions appear below.
3. Choose the CSV file and review the project and task counts. The filename becomes the project name.
4. Select **Import tasks**. Import happens directly inside Settings.
5. Check the imported project before importing another file. Re-importing the same file creates duplicates.

## What is imported

- Tasks and subtasks; deeper subtasks become direct children of their root task.
- Task descriptions and comments, as notes. Section names are also kept in notes.
- Labels on top-level tasks, as tags.
- Priorities on top-level tasks, as p1–p3 tags. Todoist's p4 stays untagged.
- Minute-based durations, as time estimates.
- Exact ISO calendar dates (YYYY-MM-DD), as scheduled dates.

## What needs checking

Completed tasks are absent from Todoist project CSV exports. Natural-language
dates and recurrence expressions are retained in notes instead of being guessed;
recreate important schedules with [[2.06-Manage-Repeating-Tasks]]. Time zones,
deadlines and assignee text are kept in notes, but reminders, assignees and attached
files are not recreated. Subtasks do not receive labels or priority tags.

If import stops partway through, check the named partial project and any already
imported projects before retrying. Delete those copies before re-importing the
same file. To undo an import, delete the created project.
