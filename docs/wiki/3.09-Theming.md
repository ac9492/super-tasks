# Theming

## Ultra Tasks workspace

Ultra Tasks adds a restrained teal-accented workspace treatment: rounded task rows, frosted navigation and header surfaces (see [Glass appearance](#glass-appearance)), and a clear active-navigation marker. Text and task content stay sharp.

Task cards have a complete, solid outline derived from the card color with low contrast. Subtasks are rows inside their parent's card, divided by a hairline. Section headings are small muted labels with no rule under them. The task you are tracking gets an accent outline, and the task open in the detail panel a soft tint, so the two never look alike.

The app uses the white Faceted comet on a deep-teal rounded square in navigation and at startup. The mark has an octagonal head and three straight geometric trails. Search is the first navigation entry, below the logo; its existing search page, feature visibility setting, and shortcuts are preserved. Task capture shows its destination project, and the detail panel provides direct planned-date and deadline actions with a short explanation of their different meanings. These changes do not alter task records or synchronization.

Ultra Tasks uses one clean interface with three colors, configured under
**Settings → General → Appearance**:

- **Background** — The main canvas and navigation background.
- **Cards and panels** — Cards, settings sections, forms, menus, and dialogs.
- **Accent** — Primary actions, the tracked task's outline, and state indicators. Selected navigation, the open task and a chosen toggle segment are soft tints derived from it.

Every combination stays readable. Light mode always has light backgrounds and
cards with dark text; Dark mode has dark ones with light text. When a chosen
color would make text, icons, or controls hard to read (for example a black
background in Light mode, a neon accent, or an accent that matches the
background), Ultra Tasks adjusts its lightness just enough and keeps its hue.
Colors that already work are used exactly as chosen. There is nothing to turn
on or off.

Secondary text, such as estimates, dates, and hints, is dimmer than the main
text but still readable on every background, card, and selected task. Disabled
controls appear dimmed. Project and tag colors identify their icons or dots
without replacing the application palette.

## Presets and custom colors

Choose Default, Sand, Forest, or Plum to apply a coordinated light/dark pair.
Each preset displays three swatches. Edit any of the three color inputs to
personalize the currently displayed mode. Changes immediately update the app and
the preview. **Reset colors** restores both default palettes.

When Ultra Tasks adjusts a color, its input keeps the color you picked and a
second swatch next to it shows the color in use (**Shown as** and its hex
value). One line under the inputs explains why: _Adjusted so text and controls
stay readable._ If you picked a dark background or card color for Light mode
(or a light one for Dark mode), the line adds that the mode keeps light (or
dark) backgrounds. The preview and the preset swatches show the colors as the
app uses them. The colors you picked are what is saved; the adjustment is only
applied on screen.

Default uses the icon's deep teal (`#075b5e`) in Light mode and a lighter teal
(`#63c5c3`) in Dark mode for contrast. Saved custom palettes keep their chosen
colors; choose Default or Reset colors to apply the current defaults.

**Light**, **Dark**, and **System** control the displayed mode. System follows the
device preference. Light and dark colors are stored separately, so switching
modes preserves your edits. In System mode, the editor indicates which palette
is currently being edited.

Palettes and mode selection are saved on this device. They do not sync or travel
with task-data exports.

## Glass appearance

**Glass appearance** (**Settings → General → Appearance**, default: on) turns
the side navigation, the header, the task detail panel and the phone's bottom
bar into frosted glass with a slight, blurred show-through. The area behind the
task list shows it only faintly. Task cards, dialogs, menus and the phone's
navigation drawer stay solid. Text
on glass keeps at least 4.5:1 contrast whatever lies behind it: where a palette
needs it, the glass tint becomes more opaque automatically.

What shows through depends on the platform:

- **Desktop app on macOS and on Windows 11 (version 22H2 or later):** the
  desktop and the windows behind Ultra Tasks, blurred by the system and matched
  to the app's Light or Dark mode. On Windows this needs **Use custom title
  bar**, and the area behind the task list stays solid so text keeps its
  ClearType smoothing; only the frame is translucent.
- **Web app, Android, iOS, Linux desktop and Windows 10:** your background image,
  blurred. Without an image, a soft gradient made from your palette colors.

**Background image** sits below the Glass switch while Glass is on (it is not
offered in the macOS and Windows 11 desktop app). Choose an image file for
**Light mode** and one for **Dark mode**; when only one is set, both modes use
it. **Remove** goes back to the gradient. Because the image is only ever shown
blurred, it is reduced to at most 256 pixels and about 24 KB before it is saved.
It is stored in your settings and syncs to your other devices. Images chosen in
earlier versions keep working.

Turn Glass off for solid surfaces; the image is then not shown. The switch is
saved on this device and not synced. The device's reduce-transparency and
high-contrast (forced colors) settings also give solid surfaces.

## Previous theme settings

Built-in CSS themes, CSS uploads, project-specific app palettes and background
images, and manual hue/contrast controls have been replaced by the three-color
picker. The app-wide background image now appears only behind
[Glass appearance](#glass-appearance), always blurred; its former overlay
opacity and blur values are no longer applied. Previously stored CSS files,
`CUSTOM_THEME` selections, `styles.css` files, and legacy project settings are
preserved but no longer applied. Electron no longer loads or watches
`styles.css`.

## Scheduled-date Badge Colors

Ultra Tasks uses matching icon and date-label colors in task rows and Board cards:

- **Overdue:** red (`--c-warn`).
- **Today:** green (`--scheduled-date-today`).
- **Tomorrow:** amber (`--scheduled-date-tomorrow`).
- **Upcoming, days 2–8:** purple (`--scheduled-date-upcoming`).

Later dates, completed tasks and the task currently being tracked use their
standard color. Timed dates turn red when their time is reached, using the
shared clock and refreshing when the app becomes active again. Pausing tracking
restores the appropriate date color. The configured start of day applies.

The colors are independent of the date display style: weekday names, compact
month labels and English ordinals all use the same palette. Red, green, amber and
purple never take the accent color; their shade follows the palette and mode so
the date stays readable on cards, hovered rows and the selected task. Errors,
warnings and success messages use the same red, amber and green. Custom CSS themes are no
longer loaded.
