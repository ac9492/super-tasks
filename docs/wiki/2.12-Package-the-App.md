# Package the App

How to build Ultra Tasks desktop packages (Electron) for Windows and macOS.

## Prerequisites

- Development environment set up ([[2.11-Run-the-Development-Server]])
- Node.js 22.22.3+, 24.15.0+ or 26+ (see `.nvmrc`)
- A Mac for macOS packages

## Build Packages

1. Compile the frontend and the Electron main process:

   ```bash
   npm run buildFrontend:prod:es6
   npm run electron:build
   ```

2. Package for Windows (installer and portable app):

   ```bash
   npx electron-builder --config electron-builder.ultra-tasks.cjs --win nsis portable --x64 --publish never
   ```

   Or, on a Mac, package for macOS (DMG and ZIP for Intel and Apple Silicon):

   ```bash
   npx electron-builder --config electron-builder.ultra-tasks.cjs --mac dmg zip --x64 --arm64 --publish never
   ```

The packages are saved in `.tmp/ultra-tasks-builds`. Windows builds are unsigned; macOS builds are ad-hoc signed and not notarized. The [Ultra Tasks desktop build notes](https://github.com/ac9492/ultra-tasks/blob/main/docs/ultra-tasks-builds.md) describe the app identity, data folder and signing.

Published releases are built by the **Desktop GitHub Release** workflow (`.github/workflows/desktop-release.yml`) with `electron-builder.desktop.yaml`; see [release and publishing](https://github.com/ac9492/ultra-tasks/blob/main/docs/release-and-publishing.md).

## Inherited `npm run dist`

`npm run dist` comes from Super Productivity. It first runs the full pre-check (lint, unit tests, integration tests and the complete E2E suite), then packages with `electron-builder.yaml`, which keeps the inherited target list (including Linux and store targets). Platform-specific overrides live under `build/`, including the `electron-builder.mas*.yaml` files for Mac App Store builds. Use the [electron-builder CLI](https://www.electron.build/cli) for one-off builds (e.g. other architectures or formats).
