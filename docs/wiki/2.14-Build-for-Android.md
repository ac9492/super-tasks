# Build for Android

How to build the Android app for Ultra Tasks.

The Android app lives in the `android/` directory of this repository and
supports **Connectivity-Free Mode** (offline-first) and **Online-Only Mode**
(compatibility). Ultra Tasks does not publish Android builds yet, so build the
app yourself to try it.

## Where to Find Instructions

Full build and configuration steps are in:

**[android/README.md](https://github.com/ac9492/ultra-tasks/blob/main/android/README.md)** (in this repository: `android/README.md`)

That README covers:

- Choosing launch mode (Connectivity-Free vs Online-Only)
- Setting `LAUNCH_MODE` in `android/app/app_config.properties`
- Step-by-step build guides:
  - [Connectivity-Free Mode](https://github.com/ac9492/ultra-tasks/blob/main/android/README_OFFLINE.md) (recommended)
  - [Online-Only Mode](https://github.com/ac9492/ultra-tasks/blob/main/android/README_ONLINE.md)
