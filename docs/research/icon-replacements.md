## Visual identity pass

The first audit focused primarily on meaning. This pass explicitly flags purpose-correct style mismatches: OS-dependent colored emoji, typography totals, heavier legacy Doc Mode paths, filled/dense generic plugin art, native checkbox shape/weight, native shortcut shell colors, and the optional decorative rocket illustration. Name aliases that resolve to identical artwork are explicitly labeled as optional code cleanup rather than visual improvements.

The baseline is the current monochrome **Material Symbols Outlined at FILL 0 / weight 400**, compact 24dp geometry, rounded-square task controls, and emerald brand. Provider logos, explicit user-selected emoji, the brand tile, intentional selected-state fills and coordinated sync-ring icons remain valid exceptions. This is icon work; it does not redesign the whole Android theme or change notification behavior.

- Retain the emerald production brand tile; do not turn it into an outlined toolbar icon.
- Retain official provider brands and their licensed forms; standardize size/alignment, not logo geometry.
- Preserve explicitly user-selected emoji/project/tag/counter icons. These findings concern shipped system defaults and UI copy.
- Retain intentional checked/rating state fill and conventional play triangles; outline consistency does not mean eliminating meaningful state differences.
- Preserve the coordinated sync-ring SVG family; it already shares a ring footprint and meaningful state variants.
- iOS/Android system action symbols may follow native conventions. Cross-platform parity is about meaning; a native stroke difference alone is not a defect.
- Main task completion and Doc Mode already use rounded checkboxes. The Android widget is the actual shape mismatch.
- The registered sp SVG is not the live app logo in sidebar, which already loads assets/ultra-tasks/logo.svg.

## Specific candidate sources

- Material candidates are exact standalone SVG paths extracted from the app's bundled font. The font SHA and axis settings are recorded in [material extraction metadata](icon-replacements/material-extraction.json); the asset pack includes its Apache license. No new runtime icon library is proposed.
- Calendar minus, calendar back and document sync candidates combine that geometry with small same-weight badges. Their composition provenance is recorded in [custom provenance](icon-replacements/custom-provenance.json).
- Google Calendar, Todoist and TickTick marks are sourced from Simple Icons, not vendor-hosted official downloads. Source URLs/blob hashes and the CC0 license are included; brand trademarks remain their owners'.
- Actual existing SVG/native paths and old Doc Mode paths are preserved for Before. SF Symbol comparisons explicitly use platform-equivalent artwork; they are not exact Apple glyph renders. Native SF availability, Android export/masking and actual device sizes need verification during implementation.
- Runtime-provider comparisons use actual GitHub artwork as a clearly labeled example; the implementation should retain the configured provider. Three plugin fill risks are source-derived and not claimed as reproduced screenshot defects.

## Refinements from the earlier suggestions

- Finish task alias normalization is narrowed to the actual focus-row done glyph; regular task controls are already consistent.
- Standing counter: man (stationary person), replacing the earlier accessibility_new suggestion.
- Stretching counter: accessibility_new (outstretched arms), replacing meditation/self_improvement.
- Headings: exact format_h1 / format_h2 / format_h3 glyphs are available.
- Automatic placement: calendar_clock, avoiding the earlier sparkle alternative.
- Streak durations: calendar_month with explicit day count, unifying earlier event_available/emoji suggestions.
- Voice Reminder: simple volume_up, avoiding a dense custom speaker/bell compound.
- Focus completion banner: retain actual active celebration use; the simple-counter celebration occurrence cited earlier is commented and excluded.

## Rebuild

From the repository root, after editing the snapshot inputs:

```bash
node docs/research/icon-replacements/prepare.mjs
node docs/research/icon-replacements/build-review.mjs
```

SVGs are supplied as review artifacts. To re-extract a Material glyph, use the included Python script with the existing fontTools environment and the repository's bundled font; it uses Node's Brotli decoder. Preserve the asset provenance/license files when exporting. Changes to the original audit need a fresh extraction and contextual review rather than assuming stable row numbers remain valid.
