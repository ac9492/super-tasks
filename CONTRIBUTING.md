### Licensing by directory

Ultra Tasks keeps the client and most reusable packages under MIT, while its
distributed SuperSync server is under AGPL-3.0-only. Contributions to
`packages/super-sync-server/` should be suitable for AGPL-3.0-only
distribution and must preserve inherited copyright notices and compatible
third-party license terms. Contributors retain their copyrights; this policy
does not request a copyright assignment. See [LICENSING.md](LICENSING.md)
before contributing server changes.

### Options for contributing

In case you want to contribute, but you wouldn't know how, here are some suggestions:

1. **Spread the word:** Share the [Ultra Tasks repository](https://github.com/ac9492/ultra-tasks) and help people understand its focus on a simple, customizable interface.

2. **Provide a Pull Request:** Here is a list of [the most popular community requests](https://github.com/ac9492/ultra-tasks/issues?q=is%3Aissue+is%3Aopen+sort%3Areactions-%2B1-desc) and here some info on **[how to run the development build](docs/wiki/2.11-Run-the-Development-Server.md)** (wiki). Please make sure that you're following the commit message format documented in [.github/CONTRIBUTING.md](.github/CONTRIBUTING.md#commit-message-format) and to also include the issue number in your commit message, if you're fixing a particular issue (e.g.: `feat: add nice feature #31`). If your change touches synced state (effects, reducers, bulk dispatches), read the [Contributor Sync Model](docs/sync-and-op-log/contributor-sync-model.md) first — one invariant, partly lint-enforced.

3. **[Answer questions](https://github.com/ac9492/ultra-tasks/issues?q=is%3Aissue+is%3Aopen)**: You know the answer to another user's problem? Share your knowledge!

4. **[Provide your opinion](https://github.com/ac9492/ultra-tasks/issues?q=is%3Aissue+is%3Aopen+sort%3Areactions-%2B1-desc+label%3A%22community+feedback+wanted%22):** Some community suggestions are controversial. Your input might be helpful even if it is just an up- or down-vote.

5. **[Provide a more refined UI spec for existing feature requests](https://github.com/ac9492/ultra-tasks/issues?q=is%3Aissue+is%3Aopen+label%3A%22needs+concept+and%2For+ui+spec%22)**

6. **[Report bugs](https://github.com/ac9492/ultra-tasks/issues/new)**

7. **[Make a feature or improvement request](https://github.com/ac9492/ultra-tasks/issues/new)**: Something can be done better? Something essential missing? Let us know!

8. **[Translations](docs/TRANSLATING.md)**: You don't have to be programmer to help. See our [translation guide](docs/TRANSLATING.md) for details on how to contribute translations.

9. **Support maintenance:** Test development builds, improve documentation, and help reproduce issues. A funding channel for Ultra Tasks has not been configured.
