# Security policy

Super Tasks is maintained and published by **Adrian Chase**
([@ac9492](https://github.com/ac9492)). It is an independent fork of Super
Productivity.

## Reporting a vulnerability

Use [Super Tasks private vulnerability reporting](https://github.com/ac9492/super-tasks/security/advisories/new)
to contact the maintainer privately. GitHub private vulnerability reporting is
enabled for this repository; no public email address is required.

Include the affected version or commit, platform, impact, and steps to reproduce
with sample data. Do not put vulnerability details, credentials, task contents,
or other personal data in public issues.

For ordinary bugs and questions, use the [Super Tasks issue tracker](https://github.com/ac9492/super-tasks/issues).
Reports about this fork should reach its maintainer first; inherited issues can
then be coordinated with Super Productivity as appropriate.

## Supported versions

Super Tasks is in pre-1.0 development and has no stable release series yet.
Security fixes are made on `main`; report the exact commit or development build
you tested. Older development builds are not maintained as separate branches.
